# Minutes Check — GitHub Pages edition

Upload all files in this folder to the root of a **public** GitHub repository named `minutes-check`. Upload the extracted files, not the ZIP and not the enclosing folder. Enable GitHub Pages under Settings → Pages → Deploy from a branch → main → / (root) → Save.

Open the site URL shown by GitHub Pages. Click Download Word installation file. The XML is generated with this site's address automatically. In Word for the web use Home → Add-ins → More Settings → Upload My Add-in and choose that XML. Your institution may restrict custom uploads.

No local server, development certificate, paid API, or build step is needed. This is a static application. Do not upload actual chapter minutes, slides, settings exports, review exports, or certificates into this repository. The supplied package contains only application files.

Live Word access still needs a real-account test. This edition uses the same WordApi adapter previously tested in simulation. Verify updates in a disposable document before relying on it. PPTX text import reads all embedded slide text; it does not transcribe images or speaker notes.
